# MealDash  

MealDash is a modern food delivery web application designed to provide users with a seamless and convenient food ordering experience. With real-time order tracking, secure payments, and a sleek interface, MealDash ensures both customers and admins enjoy a smooth and efficient workflow.

## Features  
- **Real-Time Order Tracking**: Monitor your order status in real time.  
- **Dynamic API Integrations**: Flexible to work with external services for better functionality.  
- **Secure Payments**: Integrated with Stripe for safe and seamless transactions.  
- **Authentication**: Auth0 provides a reliable and secure login experience.  
- **Modern UI**: Sleek and responsive design built with ShadCN.  

## Usage  
- Place food orders with ease.  
- Track your order's real-time status.  
- Make secure payments with Stripe.  
- Manage accounts and orders with an intuitive interface.  

## Technologies Used  
- **Frontend**: [React.js](https://reactjs.org/)  
- **Backend**: [Node.js](https://nodejs.org/) and [Express.js](https://expressjs.com/)  
- **Database**: [MongoDB](https://www.mongodb.com/) 
- **Authentication**: [Auth0](https://auth0.com/)  
- **UI Framework**: [ShadCN](https://shadcn.dev/)  

## Installation  

Follow these steps to set up the MealDash application locally:  

```bash  
# Clone the repository  
git clone https://github.com/MashookhKhanlol/Food-Delivery-App.git

# Navigate to the project directory  
cd mealdash  

# Install dependencies  
npm install  

# Start the application  
npm start
